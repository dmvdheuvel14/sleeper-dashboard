# Sleeper KPI dashboard

Dashboard voor de Sleeper league "Road to Glory Redraft". Bekijk het op GitHub Pages: https://dmvdheuvel14.github.io/sleeper-dashboard/

`index.html` haalt bij openen zelf live data op van api.sleeper.app; de ingebakken snapshot is de fallback.
Opnieuw bouwen: `python3 build.py` (schrijft `dashboard.html`), daarna kopiëren naar `index.html`.
